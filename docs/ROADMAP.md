# 다음에 만들 것 (아이디어 메모)

사용자가 요청한, 아직 만들지 않은 기능들이에요. 다음 작업 때 여기서부터 이어서 진행해요.

## 1. 📚 독서 기록
- 월 단위로 모아 보기: 이번 달에 읽은 책, 읽는 중인 책, 다 읽은 책
- 하루 기록에는 "오늘 읽은 책 · 몇 쪽/몇 분 · 한 줄 메모"처럼 가볍게 적기
- 책별로 시작일·완독일·별점·인상 깊은 문장 남기기(검토 필요)
- 설정의 '오늘 화면에 보일 항목'에 독서 추가

## 2. 🗓️ 월마감 (한 달 돌아보기)
- 한 달 동안의 일상을 한 화면에 모아 보기
  - 기분·에너지 흐름(달력이나 그래프)
  - 기분 좋은 순간 모음, 감사한 일·하고 싶은 것·개선하고 싶은 것 모음
  - 운동한 날·총 운동 시간, 지출 합계, 생리 기간, 읽은 책
- 월말에 "이번 달 한 줄 회고" 남기기

## 3. 📊 분석
- 예: 운동한 날 기분이 더 좋은지, 생리 전후 컨디션 변화, 요일별 기분, 지출이 많은 날의 패턴
- 기록은 기기에만 저장하는 원칙을 지키기 위해, 분석도 기기 안에서 계산하는 방식으로 먼저 검토

## 진행 메모
- 모두 사용자와 화면 구성을 먼저 상의한 뒤 만들어요.
